What is Keynova?

Keynova turns your Markdown into beautiful HTML presentations.

  • No frameworks
  • No build tools
  • Just write and present

How It Works

  1. Write Markdown
  2. Claude Code generates HTML
  3. Preview with dev server
  4. Present or deploy
.md file → Claude Code → index.html

Code Example

function greet(name) {
  return `Hello, ${name}!`;
}
